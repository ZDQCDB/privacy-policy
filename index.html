如对本隐私政策或相关事宜有任何问题，您可随时通过本隐私政策所示之联系方式与我们联系。

定义

个人信息：指以电子或者其他方式记录的能够单独或者与其他信息结合识别特定自然人身份或者反映特定自然人活动情况的各种信息。

个人敏感信息：指一旦泄露、非法提供或滥用可能危害人身和财产安全，极易导致个人名誉、身心健康受到损害或歧视性待遇等的个人信息，包括身份证件号码、个人生物识别信息、银行账号、财产信息、行踪轨迹、交易信息、14岁以下（含）儿童信息等。

设备信息：包括硬件型号、软件列表、设备MAC地址、操作系统类型和版本、唯一设备识别码（如IMEI/MEID/Android ID/SN/OPENUDID/GUID、SIM卡IMSI信息等）、设备所在位置相关信息（包括您授权的GPS位置以及WLAN接入点和基站等传感器信息）。

服务日志信息：包括用户浏览、点击查看、搜索查询、收藏记录，以及IP地址、浏览器类型、电信运营商、使用语言、访问日期和时间。

1. 我们如何收集和使用您的个人信息

在您使用PE校园服务的过程中，我们会为如下目的收集您的个人信息：

1.1 激活与基础服务

当您激活使用PE校园服务时，我们会收集您的设备信息（主要包括IMEI、IMSI、设备 MAC 地址、SUPI、SUCI、软件安装列表、位置、联系人、通话记录、日历、短信、本机电话号码、图片、音视频等），用于判断您是否是新用户。此外，收集设备信息还可用于：将设备信息方便快捷地在照片水印上显示；针对不同设备，提供精准的消息推送、升级提醒服务。

1.2 注册账号

注册PE校园用户时，我们会收集您的电话号码用于平台登录、产品售后、一对一客服服务及平台售后。

1.3 购买商品

购买PE校园的商品时，我们会收集您的姓名、电话号码、地址信息用于对订单的管理、发货及售后。

1.4 拍摄与编辑功能

PE校园为您提供拍摄和编辑照片、视频、加水印的功能或服务。为实现这一功能，我们会请求您开启相机（摄像头）、照片/相册、麦克风等敏感权限的访问。您如果拒绝授权提供某些权限，将无法使用相关的功能，但不影响您正常使用PE校园的其他功能。

1.5 地理位置与水印

当您使用PE校园拍照时，我们会在征得您的明示同意后，将您的经纬度信息和其对应地理位置的天气状况、海拔高度以水印的形式保存至您拍摄、编辑的照片中。精准定位和行踪轨迹信息属于个人敏感信息，拒绝提供该信息不影响您正常使用PE校园的其他功能。

1.6 读取系统相册

当您使用PE校园时，我们会在征得您的明示同意后，读取您的系统相册以实时统计您的拍摄照片的数量并向您进行提示。您如果拒绝授权提供，将无法使用相应功能，但不影响您正常使用PE校园的其他功能。

1.7 EXIF信息

当您拍摄或编辑照片、图片时，为实现向您提供服务并作持续优化之目的，我们将生成或获取您图片的EXIF信息（根据设备厂商的不同，EXIF信息可能包括图片拍摄与处理时的GPS、设备型号、感光度（ISO）、前后置摄像头与创建时间信息）。

1.8 分享功能

当您编辑照片、图片后使用分享功能时，为实现分享之目的，我们需要将该照片、图片上传至服务器并生成分享链接后储存在我们的服务器中。因为存储是实现这一功能所必需的，我们会以加密的方式存储。

1.9 传感器监听

您在相机页面使用拍照/拍摄功能时，需要通过监听传感器检测用户手机转向，判断是横屏或竖屏，相机水印等信息对应跟着转向。获取频率：根据您的操作，转向一次则获取一次该信息。

1.10 通讯录、短信与相机权限

通讯录及通话记录：使用一键登录功能需要获取用户的手机通讯录信息权限，获取手机号后授权进行一键登录。

短信：用户需要进行登录账号才能使用APP全部功能，可通过手机短信验证码进行登录账号，每次获取验证码需要获取短信权限。

相机：用户进行拍照、摄像需要获取使用相机权限，以保证照片视频能正常生成保存。

1.11 剪贴板信息

您拍照后分享照片，使用分享功能时，可能会访问获取您的粘贴板信息，以保证分享功能正常使用。

1.12 加速度传感器

用户在使用水印中带有"速度"、"方位角"的，需要使用到"加速度传感器"感应当前用户的速度状态。

1.13 读取WiFi扫描结果

为了加强水印"经纬度"在室内的识别精准度，需要获取WiFi扫描信息。

1.14 读取WiFi的BSSID

用于提升位置服务的准确性和可靠性。

1.15 读取WiFi的SSID

用于定位推荐附近的设备、优化网络连接。

1.16 读取设备IP

用于定位推荐附近的服务。

1.2 保障服务安全

为提高您在使用我们服务过程中的账号和信息的安全性、识别账号异常状态、了解产品适配性，我们会收集您的设备信息和/或服务日志信息。这些信息是我们提供服务和保障产品正常运行所必须收集的基本信息，用于实施我们提供的风控和安全技术，例如对PE校园系统问题进行分析，统计流量并排查可能存在的风险。

1.3 产品优化和改进

为不断改善和优化产品，我们可能会随机收集您上传的照片和视频，进行用户行为分析，以为用户提供更丰富的产品和服务。我们在收集时，会对照片和视频进行匿名化处理，以保护您的信息安全，匿名化处理后的信息不属于个人信息。

1.4 客服与售后功能

我们的客服和售后功能会使用您的账号信息，并要求您提供联系方式（手机号码、微信、邮箱）以及设备型号等信息以完成客服和售后服务沟通。为保证您的账号安全，我们的客服会使用您的账号信息与您核验您的身份。

1.5 征得授权同意的例外

您应充分知晓，以下情形中，我们收集、使用个人信息无需征得您的授权同意：

  • 与国家安全、国防安全等国家利益直接相关的；
  • 与公共安全、公共卫生、公共知情等重大公共利益直接相关的；
  • 与犯罪侦查、起诉、审判和判决执行等直接相关的；
  • 出于维护您或其他个人的生命、财产、声誉等重大合法权益但又很难得到本人同意的；
  • 所涉及的个人信息是您自行向社会公众公开的；
  • 从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开等渠道；
  • 根据您要求签订和履行合同所必需的；
  • 用于维护所提供的产品或服务的安全稳定运行所必需的，例如发现、处置产品或服务的故障；
  • 为开展合法的新闻报道所必需的；
  • 出于公共利益开展统计或学术研究所必要，且其对外提供学术研究或描述的结果时，对结果中所包含的个人信息进行去标识化处理的；
  • 法律法规规定的其他情形。

2. 我们如何共享、转让、公开披露您的个人信息

2.1 共享

2.1.1 共享原则

我们不会与PE校园服务提供者以外的公司、组织和个人共享您的个人信息，但以下情况除外：

  • 在法定情形下的共享：我们可能会根据法律法规规定、诉讼、争议解决需要，或按行政、司法机关依法提出的要求，对外共享您的个人信息。
  • 在获取明确同意的情况下共享：获得您的明确同意后，我们会与其他方共享您的个人信息。
  • 与授权合作伙伴共享：我们可能会向合作伙伴等第三方共享您的设备信息以及位置信息，以保障为您提供的服务顺利完成。但我们仅会出于合法、正当、必要、特定、明确的目的共享您的个人信息，并且只会共享提供服务所必要的个人信息。

2.1.2 第三方SDK信息

我们提供的服务可能包括属于我们的服务供应商的第三方追踪工具。该第三方可能会在我们提供的服务中使用cookies、APIs（应用程序编程接口）及SDKs（软件程序开发包），由此代表我们收集并分析用户信息。第三方可能会访问诸如您的设备标识符、MAC（媒体访问控制）地址、IMEI（移动设备国际身份码）、区域（使用给定语言的特定地点）、地理位置信息及IP地址等信息，旨在实现在其各自隐私政策下提供服务。我们的隐私政策不会覆盖到第三方追踪工具的使用。我们没有权限访问或控制这些第三方。如果您想知道更多相应第三方信息，请联系电话：16601138709。

SDK技术由与我们合作的第三方机构提供，我们仅能知悉第三方机构要求获得授权的权限，您的信息将由第三方机构收集，我们无法获取您的信息。第三方机构要求获得的权限以及明确向我们披露其收集的个人信息以以下表格为准。如您拒绝向第三方机构提示信息仅会使您无法使用第三方机构提供的技术所搭载的功能，但不影响您使用PE校园的其它功能。
